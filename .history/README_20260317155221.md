# Expo + NativeWind Template

A production-ready React Native starter with **Expo Router**, **NativeWind v4**, **TanStack Query**, **Zustand**, and the same stack as OnlyFaith — so you can bootstrap any new app in minutes.

---

## Stack

| Layer          | Library                         |
|----------------|---------------------------------|
| Framework      | Expo ~54 (new arch enabled)     |
| Routing        | Expo Router v6                  |
| Styling        | NativeWind v4 (Tailwind CSS)    |
| Animations     | React Native Reanimated v4      |
| Server state   | TanStack React Query v5         |
| Client state   | Zustand v5                      |
| Forms          | React Hook Form + Zod           |
| HTTP client    | Axios                           |
| Modals/sheets  | @gorhom/bottom-sheet v5         |
| Secure storage | expo-secure-store               |
| Fonts          | Inter (via @expo-google-fonts)  |
| Icons          | @expo/vector-icons (Ionicons)   |
| SVGs           | react-native-svg-transformer    |
| Toasts         | react-native-toast-message      |

---

## Quick Start

```bash
# 1. Copy this template
cp -r expo-nativewind-template my-new-app
cd my-new-app

# 2. Install dependencies
npm install

# 3. Set up env
cp .env.example .env
# Edit .env with your API URL and credentials

# 4. Update app identity
#    - app.json → name, slug, bundleIdentifier, package
#    - tailwind.config.js → primary/secondary colors
#    - lib/constants.ts → APP_NAME

# 5. Start dev server
npm run dev
```

## NativeWind — How It Works (critical bits)

**Three files make NativeWind work. Touch them carefully:**

### 1. `babel.config.js`
```js
presets: [
  ['babel-preset-expo', { jsxImportSource: 'nativewind' }],  // ← auto-transforms className
  'nativewind/babel',
]
```

### 2. `metro.config.js`
```js
module.exports = withNativeWind(config, {
  input: './global.css',        // ← your Tailwind entry point
  configPath: './tailwind.config.js',
});
```

### 3. `global.css` (must be imported in `app/_layout.tsx`)
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## Customising the Theme

Edit `tailwind.config.js`:
```js
colors: {
  primary: {
    DEFAULT: '#YOUR_COLOR',   // ← your brand color
    ...
  },
}
```

All `bg-primary`, `text-primary`, `border-primary` classes update automatically.

## Adding a New API Module

```ts
// api/posts.ts
import { apiClient } from './axios';

export const postsApi = {
  getAll: () => apiClient.get('/posts').then(r => r.data),
  getOne: (id: string) => apiClient.get(`/posts/${id}`).then(r => r.data),
  create: (data: any) => apiClient.post('/posts', data).then(r => r.data),
};
```

## Adding a New Zustand Store

```ts
// stores/myStore.ts
import { create } from 'zustand';

interface MyState {
  count: number;
  increment: () => void;
}

export const useMyStore = create<MyState>((set) => ({
  count: 0,
  increment: () => set((s) => ({ count: s.count + 1 })),
}));
```
